# 🌱 내 금쪽이들 - 학교 출결 및 상담 관리 웹앱

학교 현장에서 학생들의 주간 출결(`A1` 미인정결석, `A2` 기타결석)과 상담 내역을 한눈에 관리하고, **Word(`.doc`) 파일로 즉시 다운로드**할 수 있는 파스텔 톤 스크롤형 웹 애플리케이션입니다.

---

## ✨ 주요 기능 요약

1. **상단 메뉴 및 관리자/선생님 다중 로그인**
   - 상단 제목: **“내 금쪽이들”**
   - **다중 로그인 제공**: 메인 로그인 화면에서 **`[👑 관리자 로그인]`**과 **`[👩‍🏫 선생님(담임) 로그인]`**을 나란히 제공하여 각자의 권한으로 로그인
     - **관리자 계정**: 아이디 `예성원`, 비밀번호 `admin4441#` (비밀번호 분실 시 안티그래비티로 수정 요청)
     - **선생님 계정**: 관리자가 지정한 교사 아이디 입력, 비밀번호는 모두 공통 `yewon4441#`로 로그인
   - **상단 중앙 메뉴**: **`[출석부]`**, **`[상담관리]`**, **`[지원]`**, **`[담임관리]`**, **`[관리자]`**
     - 선생님(담임) 로그인 시: `[출석부]`, `[상담관리]`, `[지원]`, `[담임관리]` 노출 (관리자 메뉴는 보안상 숨김)
     - 관리자 로그인 시: 모든 메뉴 노출 및 상단에 **`[🏫 학급 전환]`** 드롭다운이 활성화되어 각 선생님의 학급 데이터를 직접 열람/관리 가능

2. **[출석부] (주간 단위 + 휴업일 + 결석 A/B 자동 계산 & 경고)**
   - 미인정결석은 **`A`**, 기타결석은 **`B`**로 직접 입력
   - **스마트 입력 지원**: 한글 오타(`ㅁ` -> `A`, `ㅠ` -> `B`), 숫자 단축키(`1` -> `A`, `2` -> `B`), 대소문자 무관 입력 가능
   - **스페이스바 원클릭 변경**: 출결 셀에서 `스페이스바`를 누르면 `빈칸` ↔ `A` ↔ `B` 순으로 쉽게 전환
   - 휴업일 체크 시 회색 비활성화 및 연속결석 자동 연결 계산
   - 미인정 누적(A), 모든결석 누적(A+B), 연속5일(노랑), 누적35일(초록), 50일 이상(주황) 실시간 자동 집계

3. **[상담관리] 통합 [상담] 메뉴 및 기본자료/상담기록 일원화**
   - **깔끔해진 학생상담 목록**: 불필요한 출결요약 열과 기본자료 요약 텍스트를 정리하고 단일 **`[💬 상담]`** 버튼으로 통합
   - **통합 상담 모달 제공**: 학생의 **[기본자료]**(가정형태, 경제적 형편, 진로희망, 모범/관심태도, 지도방안)와 **[상담 기록]**을 한 화면에서 편리하게 관리
   - **독립적인 기본자료 수정 날짜 & 저장**: 컴퓨터 시스템 날짜에 구애받지 않고 기본자료 수정 날짜를 사용자가 직접 설정하고 별도의 **`[기본자료 저장]`** 버튼으로 개별 저장
   - **상담 행 추가 및 인라인 편집**: 하단 상담 기록 영역에서 **`[+ 행 추가]`**를 눌러 원하는 날짜와 내용을 직접 입력·저장·수정·삭제 가능
   - 3줄 초과 시 자동 스크롤되는 상담 내용과 함께 개인 상담기록부 및 Word(`.doc`) 파일에 일자별로 깔끔하게 정리

4. **각 계정별 독립적인 출석부·상담 새로운 양식 제공**
   - 선생님 계정마다 본인 학급 전용의 독립된 데이터 저장소가 배정되어 출석부와 상담 새로운 양식이 깨끗하게 제공됨
   - 다른 계정의 데이터와 섞이지 않으며, 관리자는 학급 전환 기능을 통해 전체 학급을 모니터링 가능

5. **[담임관리] 메뉴 (지원 메뉴와 관리자 메뉴 사이 신설)**
   - 담임교사가 학급 운영에 필요한 관리자급 기능을 손쉽게 사용할 수 있도록 전용 메뉴 신설
   - **담임 [출석부] 명단 설정**: 본인 학급 학생 학번·이름 행 추가, 저장, 수정, 삭제
   - **담임 [상담관리] 내역**: 학급 상담 내역 확인, 개별/전체 Word(`.doc`) 다운로드, 삭제
   - **담임 [출결관리]**: 출결 특이사항 해당 학생 집중 관리 뷰 및 전체 Word 다운로드 지원

6. **관리자 전용 [선생님(교사) 계정 관리]**
   - 관리자 메뉴에서 교사 아이디(교사명), 비밀번호(기본: `yewon4441#`), 담당 학급/비고를 등록·수정·삭제 가능한 표(Table) 제공
   - 관리자가 지정한 아이디로 등록 즉시 선생님 로그인이 활성화되며, 비밀번호는 `yewon4441#`로 로그인 가능 (각 계정별 독립된 출석부 및 상담 양식 제공)
   - 전체 데이터 백업(.json) 및 복원 시 교사 계정과 학급별 데이터 전체가 안전하게 보존됨

## 🚀 실행 및 배포 방법 (GitHub + Vercel + Firebase)

### 1. 로컬에서 바로 실행하기
별도의 빌드 과정 없이 `index.html` 파일을 더블클릭하거나 VS Code Live Server 등으로 열면 바로 작동합니다.

### 2. GitHub에 코드 올리기
바탕화면의 `내금쪽이들` 폴더에서 터미널(PowerShell)을 열고 아래 명령어를 실행하세요.
```powershell
cd "$HOME\Desktop\내금쪽이들"
git init
git add .
git commit -m "feat: 내 금쪽이들 출결 및 상담 관리 웹앱 초기 버전"
git branch -M main
git remote add origin https://github.com/<사용자아이디>/<저장소이름>.git
git push -u origin main
```

### 3. Vercel 배포하기
1. [Vercel 대시보드](https://vercel.com)에 로그인 후 **Add New... -> Project**를 클릭합니다.
2. 방금 푸시한 GitHub 저장소를 **Import**하고 **Deploy** 버튼을 누르면 `vercel.json` 설정에 따라 즉시 배포가 완료됩니다.

### 4. Firebase 실시간 데이터베이스(Firestore) 연동하기
1. [Firebase 콘솔](https://console.firebase.google.com/)에서 새 프로젝트를 생성하고 **Firestore Database**를 활성화합니다.
2. 프로젝트 설정에서 웹 앱(`</>`)을 추가하여 `apiKey`, `projectId`, `appId`를 복사합니다.
3. 웹앱 상단 `[관리자]` 섹션 우측의 **`[Firebase / GitHub 연동 설정]`** 버튼을 눌러 값을 입력하고 저장하면 실시간 클라우드 동기화가 활성화됩니다.
