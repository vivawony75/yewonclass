# 🌱 내 금쪽이들 - 학교 출결 및 상담 관리 웹앱

학교 현장에서 학생들의 주간 출결(`A1` 미인정결석, `A2` 기타결석)과 상담 내역을 한눈에 관리하고, **Word(`.doc`) 파일로 즉시 다운로드**할 수 있는 파스텔 톤 스크롤형 웹 애플리케이션입니다.

---

## ✨ 주요 기능 요약

1. **상단 메뉴 및 관리자 로그인 보호**
   - 상단 왼쪽 제목: **“내 금쪽이들”**
   - 상단 중앙 메뉴: **`[출석부]`**, **`[상담관리]`**, **`[관리자]`** (관리자 로그인 시에만 노출되며 클릭 시 해당 영역으로 부드럽게 스크롤 이동)
   - 아이디·비밀번호 변경이 필요할 때는 안티그래비티(Antigravity)에게 요청하여 수정할 수 있습니다.

2. **[출석부] (1주일 단위 + 휴업일 + 자동 누적/연속 경고)**
   - **1열**: 번호(학번) / **2열**: 이름 (`[관리자]` 메뉴에서 설정)
   - **3열~5열(월~금요일)**: 컴퓨터 시스템 날짜 기준 해당 주의 월~금 날짜 표시, 좌우 화살표(`◀`, `▶`)로 주간 이동
   - **휴업일 체크**: 각 날짜 아래 `휴업일` 체크박스를 선택하면 해당 열이 회색으로 변경되고 결석 입력이 비활성화됨
   - **출결 직접 입력**: 빈칸으로 두며 미인정결석은 **`A1`**, 그 외 결석은 **`A2`**로 직접 타이핑
   - **6열**: 미인정결석 누적(`A1`)
   - **7열**: 모든 결석 누적(`A1+A2`)
   - **8열(연속5일)**: `A1` 연속 5일 이상일 때 **노란색** 표기 (토·일요일, 법정공휴일, 체크한 휴업일은 앞뒤로 자동 연결하여 연속 일수 계산)
   - **9열(누적35일)**: `A1` 누적 35일 이상일 때 **초록색** 표기
   - **10열(누적50일)**: `A1` 누적 50일 이상일 때 **빨간색** 표기

3. **[상담관리] 및 상담카드**
   - 출석부 순서대로 학번, 이름, `[상담]` 버튼, 상담 누적 수 표기
   - `[+ 상담 행 추가 / 새 상담 작성]` 버튼 제공, **10줄 초과 시 자동 스크롤바** 생성
   - **상담카드 포함 항목**:
     - 학번, 이름, 출결사항(출석부 6열~10열 실시간 자동 반영)
     - 가정형태: 양부모, 한부모(아버지), 한부모(어머니), 조부모, 다문화 *(복수 선택 가능)*
     - 경제적 형편: 상, 중상, 중, 중하, 하 *(체크)*
     - 진로희망: 대학진학, 취업, 진로탐색, 기타(직접 기록) *(체크)*
     - 문제행동: 흡연, 음주, 나태함, 학교폭력, 교권침해 *(체크)*
     - 날짜(자동 표기) 및 상담내용(직접 입력, **3줄 초과 시 자동 스크롤**)

4. **[관리자] 메뉴**
   - **[출석부] 명단 관리**: 1열 학번, 2열 이름 행 추가 및 행 끝 `저장` / `수정` / `삭제` 버튼 제공
   - **[상담관리] 내역 리스트**: 날짜, 학번, 이름 표기 + `내용보기` 모달 및 **Word(`.doc`) 파일 다운로드**
   - **[출결관리] 전용 버튼**: 출석부 6열~10열에 해당하는 학생들만 상담 내용과 함께 정리하여 `내용보기` 및 **Word 다운로드** 지원

## 🚀 실행 및 배포 방법 (GitHub + Vercel + Firebase)

### 1. 로컬에서 바로 실행하기
별도의 빌드 과정 없이 `index.html` 파일을 더블클릭하거나 VS Code Live Server 등으로 열면 바로 작동합니다.

### 2. GitHub에 코드 올리기
바탕화면의 `내금쪽이들` 폴더에서 터미널(PowerShell)을 열고 아래 명령어를 실행하세요.
```powershell
cd "$HOME\Desktop\내금쪽이들"
git init
git add .
git commit -m "feat: 내 금쪽이들 출결 및 상담 관리 웹앱 초기 버전"
git branch -M main
git remote add origin https://github.com/<사용자아이디>/<저장소이름>.git
git push -u origin main
```

### 3. Vercel 배포하기
1. [Vercel 대시보드](https://vercel.com)에 로그인 후 **Add New... -> Project**를 클릭합니다.
2. 방금 푸시한 GitHub 저장소를 **Import**하고 **Deploy** 버튼을 누르면 `vercel.json` 설정에 따라 즉시 배포가 완료됩니다.

### 4. Firebase 실시간 데이터베이스(Firestore) 연동하기
1. [Firebase 콘솔](https://console.firebase.google.com/)에서 새 프로젝트를 생성하고 **Firestore Database**를 활성화합니다.
2. 프로젝트 설정에서 웹 앱(`</>`)을 추가하여 `apiKey`, `projectId`, `appId`를 복사합니다.
3. 웹앱 상단 `[관리자]` 섹션 우측의 **`[Firebase / GitHub 연동 설정]`** 버튼을 눌러 값을 입력하고 저장하면 실시간 클라우드 동기화가 활성화됩니다.
